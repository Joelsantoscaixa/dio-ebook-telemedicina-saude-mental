## 📌 Descrição do projeto
Este projeto compila um eBook prático sobre **Telemedicina aplicada à Saúde Mental e ao Bem‑Estar Corporativo**, com foco em PMEs e conformidade com a **NR‑1**. O material foi gerado e organizado a partir de prompts, seguindo as instruções do desafio da DIO.

## ✅ Como entregar
1) Faça o **fork** ou crie um **novo repositório** no GitHub com estes arquivos.
2) **Coloque o eBook** na pasta `ebook/` (já incluso).
3) No **README**, mantenha o link do **ARTIGO** (abaixo) e do **repositório de referência**.
4) Envie o **link do seu repositório** no painel de entrega da DIO.
